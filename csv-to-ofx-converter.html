How to use it

  1. Download your transactions as CSV from online banking (or export them from a spreadsheet).
  2. Choose the file. The tool detects the separator (comma, semicolon or tab), the header and the usual column names (Date, Description, Amount, Debit, Credit, Balance, and their Spanish equivalents).
  3. Check the preview. If the bank has separate money-in and money-out columns, pick "two columns".
  4. Pick the format and download.

The balance check

If your CSV has a balance column, select it. The tool then checks that each row's amount takes the previous balance to the new one, in either date order, and lists the rows where it doesn't. A row that fails usually means a missing line, a duplicate, or an amount with the wrong sign. It's worth fixing before you import, because accounting software will accept a wrong file without complaint.

Which format should I pick?

  • OFX: the most widely accepted. Quicken, QuickBooks Desktop, Xero, Wave, GnuCash, YNAB, Moneydance, Banktivity. Each transaction gets a stable ID, so re-importing the same rows doesn't create duplicates in most apps.
  • QuickBooks Online CSV: the 3-column layout (Date, Description, Amount, dates as MM/DD/YYYY). See the QuickBooks CSV format explained.
  • Xero CSV: Xero's statement import template (dates as DD/MM/YYYY). See the Xero CSV format.
  • QIF: for older Quicken versions, MoneyWiz and apps that don't read OFX. More on both in OFX vs QIF.

Is it safe?
