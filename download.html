Install in 3 steps

  1. Unzip LedgerProof-Lite.zip (right-click → Extract all on Windows; double-click on Mac).
  2. Install once: double-click INSTALL.bat on Windows, Install (Mac).command on Mac, or run install.sh on Linux. It sets everything up inside the folder and needs internet the first time (a few minutes). If Python isn't installed, it downloads the official one from python.org.
  3. Start: double-click START.bat (Windows) or Start (Mac).command. LedgerProof opens in your browser but runs on your computer. Drop in a PDF statement, or try the samples in the sample_data folder.

Windows may show a SmartScreen warning because the installer isn't code-signed: click More info → Run anyway. On Mac, if it says the file can't be opened, right-click it and choose Open.

What Lite does

  • Converts 2 PDF statements at a time to Excel and CSV.
  • Checks every row against the balances printed on the statement and flags the ones that don't add up.
  • Works offline. Nothing is uploaded.
