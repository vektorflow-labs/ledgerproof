What it checks

Each account in a Norma 43 file ends with a closing record (33) holding the number of debits and credits, the total of each and the closing balance. The page recalculates all of it from the transactions:

  • Number of entries: debits and credits read match the counts the bank declares.
  • Total debits and total credits: match to the cent.
  • Closing balance: opening + credits − debits equals the closing balance in the file.
  • Continuity: when the file holds several periods of the same account, each opening balance equals the previous closing balance.
  • Record count: the end-of-file record (88) counts the lines, so a truncated download is caught.

What's in the Excel file

One row per transaction with transaction date, value date, description (the 23 concept records joined), amount (debits negative), balance after each transaction, common concept code with its meaning, the bank's own concept code, document number, references 1 and 2, original currency and amount (record 24, when present) and account. Dates are real Excel dates and amounts are numbers, with filters and a total row.

The Norma 43 format in short

  • 11 account header: bank, branch, account number, start and end dates, opening balance and its sign, currency (ISO numeric: 978 is EUR), account holder.
  • 22 transaction: transaction and value dates (YYMMDD), common and bank concept codes, debit (1) or credit (2) at position 28, amount at positions 29 to 42 with two implied decimals, document number and references.
  • 23 description lines, up to 5 per transaction. 24 optional original currency and amount.
  • 33 account end: number and total of debits and credits, closing balance. 88 end of file with the record count.

Questions

What is a Norma 43 file?

It's the Spanish Banking Association's standard (Cuaderno 43) for delivering account transactions in a file. Many banks in Spain offer it, mainly in business online banking, and many accounting programs import it. Files usually end in .n43 or .txt.

Is my file uploaded?

No. Your browser reads the file and builds the download on your computer. There's no server behind the page: you can go offline after it loads and it keeps working.

Can I import it into QuickBooks Online or Xero?
