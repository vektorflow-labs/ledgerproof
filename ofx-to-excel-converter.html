What the check tells you

  • Duplicate transaction IDs. Banks give every OFX transaction an ID (FITID). If the same ID shows up twice in one account, one of the rows is probably a duplicate.
  • Implied opening balance. When the file includes the closing balance, the page subtracts the transactions to get the balance the period started with. Compare it with the closing balance of the previous statement: if they don't match, a transaction is missing or extra.
  • Repeated rows. Rows with the same date, amount and description are listed so you can look at them. Two identical coffees on the same day are real; two identical rent payments probably aren't.

What's in the Excel file

OFX, QFX, QBO and QIF

  • OFX (Open Financial Exchange) is the standard bank download format. Versions 1.x look like unclosed tags; 2.x is XML. Both work here.
  • QFX is Quicken's name for an OFX file with an extra Intuit header. Same content.
  • QBO is QuickBooks Web Connect, also OFX inside. Don't confuse it with QuickBooks Online.
  • QIF is the older Quicken text format. It has no transaction IDs and no closing balance, and dates can be month-first or day-first, so the page lets you choose.

More on choosing between them in OFX vs QIF.

Questions

Can Excel open an OFX file directly?

Not in a useful way. Excel has no OFX import, so the file opens as text full of tags like <STMTTRN> and <TRNAMT>. Converting it to .xlsx or CSV first gives you one clean row per transaction.

Is my bank file uploaded?

No. The page reads the file with your browser and builds the download there. There's no server behind it: you can go offline after the page loads and it keeps working.

Can I convert QIF to OFX, or OFX to QIF?

Yes. Open a QIF file and choose OFX as the format, or open an OFX/QFX file and choose QIF. Check numbers, payees, memos and QIF categories are carried over.

Can I import the result into QuickBooks Online or Xero?

Yes. Choose "QuickBooks Online CSV" (Date, Description, Amount with MM/DD/YYYY dates) or "Xero CSV" (Xero's statement template). Details in the QuickBooks CSV format and the Xero CSV format.
